## 🎯 주요 학습 내용

### 1. R 프로그래밍 기초

- R 설치 및 환경 설정
- 데이터 프레임(Data Frame) 다루기
- 데이터 정제(Data Cleaning)
- 데이터 변환 및 가공

### 2. 통계 분석

- 기술통계(Descriptive Statistics)
- 가설검정(Hypothesis Testing)
- 추정(Estimation)
- 상관분석 및 회귀분석

### 3. 실습 및 응용

- 실제 데이터셋 분석
- 분석 보고서 작성법
- 데이터 시각화
